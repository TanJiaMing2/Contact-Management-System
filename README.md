# Contact Management System

A Data Structures and Algorithms project created during my diploma studies.

## How to Run

1. Download or clone this repository.
2. Run the `.exe` file to demonstrate the system.
3. If the program does not run, install **TDM-GCC**:

   https://jmeubank.github.io/tdm-gcc/download/
